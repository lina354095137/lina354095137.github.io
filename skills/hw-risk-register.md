# 硬件开发风险管理助手

把硬件开发的风险管理做成一张 Excel 登记册：识别 → 评分 → 分级 → 缓解 → 跟踪闭环。内置的风险知识库来自硬件 NPI 真实经验，覆盖五大风险域，init 一步生成，不用从零想。

## 快速开始

### 阶段1：生成风险登记册

用户说"帮XX项目建风险登记册，现在在DVT阶段"时：

```
python3 scripts/generate_register.py init --project 智能插座X1 --stage DVT
```
脚本按 DVT 阶段从知识库挑选适用风险（通用+技术+供应链+认证+成本+量产六大类），生成 `{项目名}_风险登记册.xlsx`。每条风险带：

- 行业经验默认评分（L可能性1-5 × S影响1-5 = R风险值）

- 建议缓解措施（可直接采用，也可按项目实际改）

- 责任人/目标日期/状态列（待填）

**重要** ：默认评分是行业经验值，生成后引导用户逐条按项目实际调整——这正是风险评审会议的议程。

### 阶段2：评估与报告

评分调整完（或每周例行）跑评估：

```
# 单项目：重算R与等级，输出分级统计+极高风险清单+TOP10
python3 scripts/generate_register.py assess --register 智能插座X1_风险登记册.xlsx

# 批量：扫描目录下所有项目登记册，谁的风险敞口大一目了然
python3 scripts/generate_register.py assess --batch-dir data/risk_registers/
```
报告自动标出：

- **极高风险** （R≥15）：建议项目周会逐条过

- **TOP风险** ：按风险值降序前10

- **逾期未缓解** ：目标日期已过还在缓解中的，单独列出

### 阶段3：状态维护

用户在Excel里更新状态列（只用这5个词：`识别` / `缓解中` / `已缓解` / `已关闭` / `已接受`），下次assess自动反映。缓解措施落地成具体整改事项时，用「硬件项目问题跟踪助手」建问题台账，风险ID填进"关联风险ID"列，两边闭环对得上。

## 触发方式

| 用户说 | 做什么 |
|---|---|
| 建风险登记册 / 项目风险管理 | init生成登记册 |
| 这个项目有什么风险 / 帮我识别风险 | init + 解读生成的风险清单 |
| 评估风险 / 风险报告 / 极高风险有哪些 | assess |
| 批量看项目风险 / 多项目风险对比 | assess --batch-dir |
| 这个风险怎么缓解 | 读知识库mitigation字段 + 结合项目情况给建议 |

## 示例对话

**用户** ：帮我给智能插座X1建个风险登记册，现在在DVT阶段 **助手** ：跑 init → 输出21条适用风险（通用4/技术6/供应链4/认证5/成本1/量产1），说明默认评分是行业经验值，建议开个风险评审会逐条调整L/S分值

**用户** ：评估一下，周会要用 **助手** ：跑 assess → 极高5项/高14项，极高风险清单（新料未验证、长交期料、独家供应、EMC、认证周期5条），TOP10排序，逾期标红

## 风险知识库维护

`templates/risk-library.yaml` 按用户行业特点自行增删改（文件头有字段说明），脚本每次读取最新内容。比如纯内销项目可删海外认证条目，用注塑外壳的产品保留开模相关风险。

## 数据与文件约定

- 工作目录：`data/risk_registers/`（登记册Excel和评估报告在这里）

- 文件命名：`{项目名}_风险登记册.xlsx` / `{项目名}_风险评估报告.txt`

- 日期统一 `YYYY-MM-DD`；状态只用五档枚举词；本技能与「硬件项目问题跟踪助手」通过"关联风险ID"列双向衔接（问题台账K列 = 风险登记册风险ID）

## 与技能族联动

- **硬件项目问题跟踪助手** ：风险缓解措施要落地时，转成问题跟踪闭环，风险ID双向关联

- **硬件项目排期助手** ：极高风险影响里程碑时，回排期调整计划

- **智能硬件采购业务助手** ：供应链风险（独家料/长交期料）的缓解动作涉及询价备选料时用
