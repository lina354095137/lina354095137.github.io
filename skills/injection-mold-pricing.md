## 重要声明

本skill基于公开行业数据整理的成本分解模型，**输出的是参考底价区间，不是精准报价** 。实际模具价格受工厂具体情况、工艺复杂度、市场行情等多因素影响，skill输出的结果仅供采购谈判参考，不作为最终定价依据。

**核心价值** ：帮助新手采购在收到报价时有一个基准线，判断"这个报价是合理的还是被宰了"，并在谈判时有具体的成本拆解作为筹码。

## 适用场景与用户定位

**适用场景** ：当有模具报价需求时，使用本skill进行模具费用预估摸底，确认基本的风险点跟方向。

**目标用户** ：初入行或没有接触过注塑行业的采购新手。

**输出定位** ：通过对多维度的考量分析，提供综合的参考意见，锚定模具的基础价格用于后续谈判评估。因为采购议价涉及到多方位的考量因素，本技能仅提供参考方向的确认，不作为实际议价依据。

**数据说明** ：

- 计算过程中涉及到的公开材料成本为最新的行业数据

- 管理成本有弹性的空间，可根据各自对供应商管理的预期进行实际的调整

## 不适用场景

以下情况**不适用** 本skill，使用前请先确认：

1. **非注塑工艺** ：本skill仅适用于注塑模具。压铸模具（锌/铝/镁合金）、钣金冲压模具、吹塑模具、挤塑模具、硅胶模具的成本结构完全不同，不能混用

2. **非塑胶材料** ：仅适用于热塑性塑料（ABS/PC/PMMA/PP/PE/PA/POM等）。不适用于热固性塑料、橡胶、液态硅胶（LSR）等

3. **高精密光学件** ：镜头、导光板等光学级精度要求超出常规注塑范畴，需专用光学模具方案，本skill参数不覆盖

4. ~双色/多色注塑~ → **已支持** ，见Step 2.5

5. ~嵌件注塑~ → **已支持** ，见Step 2.6

6. **已有模具修模改模** ：本skill针对新开模具。修模/改模/复制模具的报价逻辑不同，不适用

7. **极小批量打样** ：如果总需求<500件，3D打印或复模可能比开模具更划算，不需要用本skill算模具成本

8. **非中国大陆地区** ：参数基于国内市场行情，海外模具厂的钢材价格、人工成本、管理费率差异大

## 背景与数据来源

注塑模具报价的透明度很低，同一套模具不同厂家报价差异可达3-5倍。核心原因：

1. 工厂规模不同：管理费率、利润率、人工成本差异大

2. 工艺定义不同：对"精密模具""高光面"的理解和报价口径不一致

3. 接单意愿不同：大厂可能嫌量小故意报高价劝退

本skill的成本模型基于：

- 模具钢材公开市场价格（P20/718H/NAK80/S136等）

- 注塑机台时费行业基准

- 模具加工工序工时参考

- 不同规模工厂的管理费率/利润率经验值

- 模具寿命5级分类标准

数据详见 `data/knowledge_base.json`。

## 使用流程

### Step 1：收集输入信息

**重要：本skill不需要也不接收图纸文件上传。**  采购人员从图纸上手动提取以下关键参数即可。这样既避免图纸受控问题，也降低了使用门槛。

向用户确认以下参数（必须）：

| 参数 | 说明 | 从图纸哪里看 | 示例 |
|---|---|---|---|
| 零件名称 | 每个零件叫什么 | — | 面盖/本体壳/压条 |
| 材质 | 塑料牌号 | 图纸技术要求栏 | ABS/PC/PMMA，阻燃V-0等 |
| 数量 | 每台产品几个 | 装配图BOM | 1件/2件 |
| 颜色 | 颜色要求 | 图纸备注 | 白色/PANTONE色号 |
| 表面纹理 | 外观要求 | 图纸技术要求 | 高亮面/亚光磨砂/咬花 |
| 产品最大尺寸 | 长×宽×高 | 图纸标注 | 120×80×30mm |
| 平均壁厚 | 主壁厚 | 图纸剖面标注 | 2.0mm |
| 模具寿命要求 | 预计总产量 | 不在图纸上，采购自定 | 10万次/30万次 |
| 精度要求 | 公差等级 | 图纸公差标注 | 普通级/精密级 |
| 年度产能 | 年需求量 | 不在图纸上，采购自定 | 5万套/年 |
| MOQ | 单次起订量 | 不在图纸上，采购自定 | 500/1K/5K |

可选信息（有则更准）：

| 参数 | 说明 | 为什么有用 |
|---|---|---|
| 开模工期 | 可接受的交期 | 影响加急费用 |
| 目标价 | 心里能接受的上限 | 帮助筛选厂档位 |
| 厂家报价单 | 已收到的报价 | 用于偏离度分析 |
| 工厂位置偏好 | 省市/距离要求 | 物流成本 |
| 工厂性质偏好 | 个体/民营/合资/外资 | 信用风险 |
| 复杂度备注 | 有无倒扣、侧抽芯、绞牙等 | 影响模具结构复杂度 |

**关于复杂度判断的提示：** 如果采购不确定产品复杂度，可以让采购描述一下零件特征，skill根据以下规则判断：

- 有倒扣/侧抽芯 → 复杂度+

- 有绞牙（螺纹） → 复杂度+

- 有嵌件注塑 → 复杂度+

- 壁厚不均匀（过渡>0.5mm） → 复杂度+

- 多色/双料注塑 → 复杂度++

- 透明件 → 工艺要求+

### Step 2：成本分解计算

对每个零件执行以下计算：

#### 2.1 材料成本

```
单件材料费 = 单件重量(g) × 材料单价(元/吨) / 1000000
```
- 材料单价从 knowledge_base.json 的 plastic_material_prices 中查询

- 单件重量需从3D图纸获取，或由用户输入

- 阻燃/玻纤增强等特殊规格需加价

#### 2.2 模具钢材成本

根据模具寿命等级选择钢材：

- 寿命≤10万次 → P20/718H（四级/五级）

- 寿命10-30万次 → 718H/2738（四级）

- 寿命30-50万次 → 2738/NAK80（三级）

- 寿命50-100万次 → NAK80/S136（二级）

- 寿命>100万次 → S136/H13（一级）

```
模具钢材费 = 钢材重量(kg) × 钢材单价(元/kg)
```
- 钢材重量 ≈ 模架尺寸 × 钢材密度 × 系数1.2（含损耗）

- 模架尺寸根据产品尺寸+腔数估算

#### 2.3 加工费

```
加工费 = CNC工时×CNC单价 + EDM工时×EDM单价 + 线切割工时×线切割单价 + 钳工工时×钳工单价
```
- 各工序单价从 knowledge_base.json 的 mold_processing_rates 中查询

- 工时估算需根据产品复杂度（简单件/中等件/复杂件）

#### 2.4 其他费用

```
热处理费 = 钢材费 × (3%~8%)
设计费 = (材料费+加工费) × (5%~10%)
试模费 = (材料费+加工费) × (2%~5%)
管理费 = (材料费+加工费) × 管理费率
利润 = (材料费+加工费+管理费) × 利润率
税费 = 小计 × (3%~6%)
```
- 管理费率和利润率根据工厂类型从 factory_type_profiles 中查询

#### 2.5 双色/多色注塑附加成本（如适用）

**典型应用场景** ：牙刷柄（TPR软胶+PP硬胶）、电源按键（PC透明+ABS着色）、汽车内饰件（硬塑+软触面）、电动牙刷外壳、剃须刀手柄等需要"硬软结合"或"多色一体成型的产品。

如果产品为双色或多色注塑，在常规计算基础上增加：

```
双色模具结构费 = 常规加工费 × 复杂度系数(1.5~2.0)
三色模具结构费 = 常规加工费 × 复杂度系数(2.0~3.0)
双色注塑机台时费 = 150~300元/h（替代常规机台费）
```
**复杂度系数选择依据** ：

- 1.5倍：两色同材质（如ABS白+ABS灰），注塑顺序简单，无结合力问题

- 1.8倍：硬胶+软胶组合（如ABS+TPE），需要验证结合力，注塑顺序有要求

- 2.0倍：三色或带嵌件+多色，结构复杂度显著增加

**与单色模具的核心区别** ：

1. 模具结构：需要旋转中板或滑块机构，实现两次/多次注塑在一次成型周期内完成

2. 机台要求：必须使用双色注塑机（有两套塑化系统），普通注塑机无法生产

3. 工艺调试：注塑顺序、温度匹配、保压时间都需要调试，试模次数通常比单色多2-3次

需额外向用户收集：

- 色数（2色/3色）

- 硬胶+软胶组合（如ABS+TPE）

- 注塑顺序（先硬后软还是先软后硬）

风险提示：

- 必须核查工厂是否有双色机台和同类案例（很多小厂只有单色机）

- 硬软胶结合力需验证材质兼容性（TPE与ABS结合力尚可，与PP结合力较差）

- 双色模具修模成本远高于单色，建议前期充分确认设计

#### 2.6 嵌件注塑附加成本（如适用）

如果产品含嵌件，在常规计算基础上增加：

```
嵌件成本 = 嵌件单价 × 每模嵌件数
嵌件模具附加费 = 常规模具费 × (5%~15%)（定位结构+预热装置）
嵌件放置人工 = 周期延长系数 × 注塑成本
```
需额外向用户收集：

- 嵌件类型（铜螺母/冲压件/塑胶件）

- 嵌件单价

- 每模嵌件数

- 放置方式（手工/机械手）

风险提示：

- 嵌件定位精度是关键，偏位导致废品

- 金属嵌件需预热否则结合力差

- 大批量建议机械手放置，小批量可手工

### Step 3：参考底价计算

```
参考底价 = 材料费 + 加工费 + 热处理费 + 设计费 + 试模费 + 管理费 + 利润 + 税费 + 双色附加（如适用）+ 嵌件附加（如适用）
```
输出三档参考底价：

- **大厂基准** ：按大型厂管理费率10-15%、利润率15-25%计算

- **中厂基准** ：按中型厂管理费率7-10%、利润率12-18%计算

- **小厂基准** ：按小型厂管理费率4-7%、利润率8-15%计算

### Step 4：厂级风险评估

对每个报价工厂评估：

| 维度 | 评估内容 |
|---|---|
| 位置 | 距用户城市的距离，物流成本 |
| 工厂性质 | 个体/民营/合资/外资，对应信用等级 |
| 同类经验 | 是否有同类产品案例（特别是透光/高光/精密件） |
| 特殊工艺匹配度 | 工厂是否有对应工艺能力（镜面抛光/晒纹/多腔等） |
| 报价偏离度 | 报价 vs 参考底价的偏差% |

风险提示规则：

- 大厂报价>基准×2.0 → 标记"可能为劝退策略，不建议继续谈"

- 小厂报价<基准×0.6 → 标记"价格异常低，需重点核查工艺能力和信用"

- 工厂无同类产品经验 → 标记"经验不匹配风险，外观可能不达标"

- 透光/高光产品+工厂无相关经验 → 红色预警

## 决策原则提醒

本skill输出的是价格基准和风险参考，但**最终选厂决策不能只看价格** 。以下维度必须纳入综合考量：

1. **单价合理性** ：不仅要看模具费，还要看大货单价是否合理。有些厂模具费低但单价高，总成本反而更高

2. **交期匹配** ：能否在要求时间内交付。大厂排期满可能排不上，小厂灵活但产能有限

3. **服务意愿** ：修模响应速度、沟通配合度、是否愿意配合改设计。这条最难量化但影响最大

4. **风险承受度** ：小厂价格低但稳定性差，要看你自己能接受多大风险

5. **长期合作价值** ：后续量产、改款、售后都依赖这个供应商，不是一锤子买卖

**最低价≠最优选。**  skill帮你锚定价格区间，但选厂是综合决策，需要采购人员结合实际情况判断。

## 常见问题

### Q1：参考底价和实际报价差距大正常吗？

正常。参考底价是基于公开行业数据的成本模型估算，实际报价受工厂当下接单意愿、产能利用率、工艺细节理解差异等影响，±15%以内属于合理区间。如果偏差超过30%，需要重点核查原因（是工艺定义不一致还是工厂在劝退/抢单）。

### Q2：双色注塑和嵌件注塑的附加成本怎么算的？

双色注塑在常规加工费基础上乘1.5~2.0的复杂度系数，另加双色注塑机台时费（150~300元/h，替代常规机台费）。嵌件注塑在常规模具费基础上加5%~15%（定位结构+预热装置），另加嵌件成本和放置人工费。详见Step 2.5和Step 2.6。

### Q3：我没有图纸怎么办？

本skill不需要图纸文件。你只需要从图纸上手动提取关键参数（材质、尺寸、壁厚、表面要求等）输入即可。如果连图纸都没有，可以描述零件特征，skill会根据经验值给出粗略估算，但精度会降低。

### Q4：这个skill能帮我直接选厂家吗？

不能。skill输出的是价格基准和风险参考，帮助你判断报价合理性和识别风险。最终选厂是综合决策，还需要考虑单价合理性、交期匹配、服务意愿、风险承受度和长期合作价值。参见"决策原则提醒"章节。

### Q5：工厂报价远低于参考底价，是不是捡到便宜了？

大概率不是。小厂报价低于基准×0.6时，需重点核查：①工厂是否有对应工艺能力（镜面抛光/晒纹/多腔等）②是否有同类产品案例 ③信用等级。价格异常低常见原因是工艺偷工减料或工厂不了解工艺要求，后续修模成本可能远超差价。

### Q6：模具寿命等级怎么选？

根据预计总产量选择：≤10万次选四级（P20/718H），10-30万次选四级偏高（718H/2738），30-50万次选三级（2738/NAK80），50-100万次选二级（NAK80/S136），>100万次选一级（S136/H13）。如果不确定，默认按四级估算，但模具寿命对成本影响大，建议确认。

### Q7：压铸模具能用这个skill算吗？

不能。本skill仅适用于热塑性塑料注塑模具。压铸模具（锌/铝/镁合金）、钣金冲压模具、吹塑模具的成本结构完全不同，钢材选择、加工工艺、设备费用都有本质区别，不能混用。
